Orange interaction — mobile vs desktop

Desktop trigger:hover — mouse enters element
Mobile trigger:active — finger tap only
Mobile resting stateSame as desktop default — neutral, no orange
What turns orange on tapCards (border-top + label + CTA) · Writing cards · Skills rows · Footer links
Always orange (both)Recommendations hook line · Contact "ships." · Hero accent · CTA buttons · Timeline current dot
Never permanently orangeCards · Skills bars · Footer links (these are interaction-only)
