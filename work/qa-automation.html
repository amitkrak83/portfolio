The Problem

Writing and maintaining end-to-end tests manually was a massive bottleneck in the release cycle. The team needed an autonomous system to convert plain-language feature requirements into working, executable functional tests without constant human intervention.

What I Built

Architected an 8–11 agent LangGraph system where specialized subagents handle NLP-to-test conversion, test data generation, framework-aware code generation, and CI/CD integration.

Integrated Playwright for autonomous browser actions and Pytest as the underlying framework to execute the generated code. RAG pipelines using FAISS, OpenAI Embeddings, and SentenceTransformers provide codebase-grounded context so generated tests are aware of the actual implementation details.

The Outcome

The time-to-first-test dropped from days to under 4 minutes. End-to-end test lifecycles (natural language → code generation → execution → reporting) are fully automated, achieving a potential 99% test coverage and speeding up the testing workflow by 10×.
